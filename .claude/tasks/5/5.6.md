# Task 5.6 - Apuração de uso por tenant

## Objetivo

Calcular e gravar mensalmente o uso de cada tenant: usuários, clientes, OS no mês, certificados e armazenamento de fotos.

## Tipo

backend-logica

## Arquivos a criar/modificar

- `app/Services/TenantUsageService.php` -> criar
- `app/Console/Commands/ApurarUsoDosTenants.php` -> criar
- `app/Support/RotinasAgendadas.php` -> modificar

## Contexto necessário (ler antes)

- `app/Models/TenantUsage.php` -> estrutura criada na Task 5.2
- `app/Support/TenantAtual.php` -> `comTenant()`, para apurar tenant a tenant
- `app/Support/RotinasAgendadas.php` -> fonte única das rotinas
- `app/Models/WorkOrderPhoto.php` -> onde o arquivo da foto é guardado, para somar o armazenamento

## Skills necessárias

- `laravel-arquitetura`
- `datas-timezone`

## Especificação

### O que fazer

1. `TenantUsageService`:
   - `apurar(Company $empresa, string $referencia): TenantUsage` -> conta dentro de `TenantAtual::comTenant()`: usuários ativos, clientes, OS criadas no mês da referência, certificados emitidos no mês, e soma do tamanho dos arquivos de foto em MB
   - `apurarTodos(string $referencia): array` -> percorre os tenants, isolando erro de um para não abortar os demais
   - `usoAtual(Company $empresa): array` -> apuração ao vivo do mês corrente, sem gravar, para o painel mostrar número fresco
   - Gravação com `updateOrCreate` na chave `[company_id, referencia]`

2. Comando `plataforma:apurar-uso {--referencia=} {--company=}`:
   - Sem `--referencia`, usa o mês corrente no fuso do negócio
   - Imprime a tabela por tenant e o total
   - Registra em `scheduled_task_runs` pelo mecanismo existente do Plano 1

3. Registrar em `RotinasAgendadas::DIARIAS` como `'plataforma:apurar-uso' => '03:00'`. Diária, e não mensal, para o painel mostrar o mês corrente atualizado, sobrescrevendo a apuração do mesmo mês.

### Regras de negócio aplicáveis

- Armazenamento é o cálculo mais caro. Somar o tamanho registrado no banco quando existir a coluna; se o tamanho não estiver guardado, somar via `Storage::size()` e **reportar** que gravar o tamanho na criação da foto seria melhor, sem implementar isso aqui (fora do escopo).
- Mês de referência calculado no fuso do negócio. Rodar às 03:00 UTC do dia 1 apuraria o mês anterior.
- Erro em um tenant é registrado e a apuração segue nos demais.
- A apuração é leitura pura: não altera nenhum dado de domínio.

### Critérios de aceitação

- [ ] `php artisan plataforma:apurar-uso` grava uma linha por tenant no mês corrente
- [ ] Rodar duas vezes no mesmo mês sobrescreve, não duplica
- [ ] `--company=1` apura só o tenant 1
- [ ] Erro em um tenant não impede os demais e aparece na saída
- [ ] A rotina aparece em `php artisan schedule:list` às 03:00 no fuso do negócio
- [ ] `usoAtual()` devolve números coerentes com as listagens do sistema

## Teste esperado

- Comando: `php artisan plataforma:apurar-uso --company=1 && php artisan schedule:list`
- Verificação manual: comparar a contagem de clientes apurada com a listagem de clientes do tenant
