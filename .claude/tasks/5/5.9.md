# Task 5.9 - Layout do painel da plataforma e faixa de suporte

## Objetivo

Criar o layout próprio da área `/plataforma` e a faixa de aviso que aparece enquanto o super admin está operando dentro de um tenant.

## Tipo

frontend-componente

## Arquivos a criar/modificar

- `resources/js/Layouts/PlataformaLayout.vue` -> criar
- `resources/js/Components/FaixaDeSuporte.vue` -> criar
- `resources/js/Layouts/AuthenticatedLayout.vue` -> modificar (incluir a faixa)

## Contexto necessário (ler antes)

- `resources/js/Layouts/AuthenticatedLayout.vue` -> layout atual das empresas
- `resources/js/Components/Sidebar.vue` -> padrão de navegação lateral
- `.claude/skills/frontend-design-system/SKILL.md` -> tema, cores e espaçamento

## Skills necessárias

- `frontend-design-system`

## Especificação

### O que fazer

1. `PlataformaLayout.vue`: layout com identidade visualmente distinta da área das empresas (o tema do projeto é verde; usar um tom neutro escuro na área da plataforma), para nunca haver dúvida sobre onde se está. Navegação com: Visão geral, Tenants, Planos, e sair.

2. `FaixaDeSuporte.vue`: barra fixa no topo, cor de alerta, texto "Você está operando como **{empresa}**" e botão "Sair do modo suporte" que faz `POST /plataforma/liberar`. Renderiza apenas quando `page.props.suporte.ativo` for verdadeiro.

3. Incluir `FaixaDeSuporte` no topo de `AuthenticatedLayout.vue`, acima de tudo, com o conteúdo da página deslocado para baixo enquanto ela estiver visível.

### Regras de negócio aplicáveis

- A faixa precisa ser impossível de ignorar. Operar em conta de cliente sem perceber é como se registra dado errado no tenant errado.
- Nada de emoji na faixa; usar SVG inline no padrão do projeto.
- Botão de sair do modo suporte é `POST`, não link: é ação com efeito, não navegação.
- A área da plataforma não usa o `Sidebar.vue` das empresas. Duplicar navegação é preferível a um componente com dois modos.

### Critérios de aceitação

- [ ] `/plataforma` renderiza com o layout próprio, visualmente distinto
- [ ] A faixa aparece em qualquer tela das empresas enquanto o suporte estiver ativo
- [ ] O botão de sair libera o tenant e volta para `/plataforma`
- [ ] A faixa não aparece para usuário comum, nem quando não há suporte ativo
- [ ] Layout responsivo, sem quebra em celular
- [ ] `npm run build` sem erro

## Teste esperado

- Comando: `npm run build`
- Verificação manual: assumir um tenant, navegar por três telas diferentes e conferir a faixa em todas
