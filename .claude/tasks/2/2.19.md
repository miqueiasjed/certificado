# Task 2.19 - Dashboard esconde o bloco financeiro sem permissão

## Objetivo
Ajustar a tela do dashboard para não quebrar e não mostrar espaço vazio quando
`financialStats` vier `null`, o que passa a acontecer para quem não tem
`financeiro-ver` (Task 2.18).

## Tipo
frontend-pagina

## Arquivos a criar/modificar
- `resources/js/Pages/Dashboard.vue` -> modificar

## Contexto necessário (ler antes)
- `resources/js/Pages/Dashboard.vue` -> onde `financialStats` é consumido
- `resources/js/Composables/usePermissoes.js` -> composable de permissões
- `app/Http/Controllers/DashboardController.php` -> prop enviada após a Task 2.18

## Skills necessárias
- `.claude/skills/frontend-design-system/SKILL.md`

## Especificação

### O que fazer
1. Envolver o bloco de cards financeiros com `v-if` que exija ao mesmo tempo a
   permissão (`pode('financeiro-ver')`) e a presença de `financialStats`.
2. Garantir que nenhum trecho leia `financialStats.algumaCoisa` sem guarda,
   evitando erro de runtime com a prop nula.
3. Se o grid restante ficar desbalanceado sem os cards financeiros, ajustar as
   classes de coluna para o layout continuar correto em mobile e desktop.
4. Nenhuma mudança de cor, ícone ou texto dos cards que permanecem.

### Regras de negócio aplicáveis
- JavaScript puro, sem TypeScript.
- Data exibida usa os utilitários do projeto, nunca `toLocaleDateString`.

### Critérios de aceitação
- [ ] Papel `tecnico` abre o dashboard sem erro no console e sem bloco financeiro
- [ ] Administrador continua vendo os cards financeiros como antes
- [ ] `npm run build` compila sem erro

## Teste esperado
- Comando: `npm run build`
- Verificação manual: abrir o dashboard com cada papel
