# Task 2.11 - Ações das telas respeitando permissão

## Objetivo
Esconder botões de criar, editar e excluir nas telas de maior risco quando o
usuário não tem a permissão correspondente, evitando que ele clique e receba 403.

## Tipo
frontend-pagina

## Arquivos a criar/modificar
- `resources/js/Pages/Clients/Index.vue` -> modificar
- `resources/js/Pages/WorkOrders/Index.vue` -> modificar
- `resources/js/Pages/Certificates/Index.vue` -> modificar
- `resources/js/Pages/Contracts/Index.vue` -> modificar

## Contexto necessário (ler antes)
- `resources/js/Composables/usePermissoes.js` -> API do composable (Task 2.10)
- Cada uma das quatro páginas -> localizar os botões de ação

## Skills necessárias
- `.claude/skills/frontend-design-system/SKILL.md`

## Especificação

### O que fazer
Em cada página, importar `usePermissoes` e aplicar `v-if` nos botões:

| Página | Botão novo | Botão editar | Botão excluir |
|---|---|---|---|
| Clients/Index | `cliente-criar` | `cliente-editar` | `cliente-excluir` |
| WorkOrders/Index | `ordem-servico-criar` | `ordem-servico-editar` | `ordem-servico-excluir` |
| Certificates/Index | `certificado-emitir` | `certificado-editar` | `certificado-excluir` |
| Contracts/Index | `contrato-criar` | `contrato-editar` | `contrato-excluir` |

Alteração pontual: só o `v-if` no elemento do botão e o import do composable.
Nenhuma refatoração de layout, nenhuma mudança de estilo.

### Regras de negócio aplicáveis
- Não remover o modal de confirmação existente nem trocar por `confirm()` nativo.
- Se a página não tiver algum desses botões, registrar no relatório e seguir.

- [ ] Nenhum outro comportamento das páginas mudou
