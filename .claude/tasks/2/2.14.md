# Task 2.14 - Tela de gestão de usuários da empresa

## Objetivo
Criar a página `Settings/Users/Index.vue` com a listagem de usuários, modal de
criação e edição, seletor de papel e desativação com modal de confirmação.

## Tipo
frontend-pagina

## Arquivos a criar/modificar
- `resources/js/Pages/Settings/Users/Index.vue` -> criar
- `resources/js/Components/Sidebar.vue` -> modificar (item de menu "Usuários")

## Contexto necessário (ler antes)
- `resources/js/Pages/Settings/` -> páginas de configuração existentes, para seguir o mesmo layout
- `resources/js/Components/` -> `Modal`, `PageHeader`, `Card` e o modal de confirmação já usado no projeto
- `app/Http/Controllers/UserController.php` -> props enviadas pelo `index` (Task 2.13)
- `resources/js/Composables/usePermissoes.js` -> Task 2.10

## Skills necessárias
- `.claude/skills/frontend-design-system/SKILL.md`

## Especificação

### O que fazer
1. Tabela de usuários com nome, e-mail, papel, técnico vinculado e status, mais
   badge verde/vermelho para ativo/inativo, seguindo o tema do projeto.
2. Botão "Novo usuário" visível só com `usuario-criar`; abre modal com nome,
   e-mail, senha, seletor de papel e seletor opcional de técnico.
3. Editar abre o mesmo modal preenchido, com senha opcional, e aparece só com
   `usuario-editar`.
4. Ativar/desativar usa **modal de confirmação**, nunca `confirm()` nativo, e
   aparece só com `usuario-desativar`. Texto: "Desativar [nome]? O usuário perde o
   acesso ao sistema imediatamente."
5. Erro vindo do backend (último administrador, e-mail duplicado) é exibido no
   modal, sem fechar o formulário.
6. Item "Usuários" no menu, dentro do bloco de configurações, com
   `v-if="pode('usuario-ver')"`.
7. Data exibida (criado em) usa os utilitários de data do projeto, nunca
   `toLocaleDateString`.

### Regras de negócio aplicáveis
- `<script setup>` em JavaScript puro, sem TypeScript.
- Ação destrutiva sempre com modal de confirmação.
- Layout responsivo, seguindo o padrão das outras listagens.

### Critérios de aceitação
- [ ] Administrador consegue criar, editar papel e desativar usuário pela tela
- [ ] Tentativa de desativar o último administrador mostra a mensagem de erro na tela
- [ ] Nenhum `confirm()` nativo no arquivo
- [ ] Nenhum `toLocaleDateString` no arquivo
- [ ] `npm run build` compila sem erro

## Teste esperado
- Comando: `npm run build`
- Verificação manual: percorrer criar, editar e desativar como administrador

alta - ~280 linhas | 2 arquivos
