# Task 2.10 - Composable de permissões e menu filtrado

## Objetivo
Criar o composable `usePermissoes` e aplicá-lo no `Sidebar.vue`, escondendo do menu
o que o usuário não pode acessar.

## Tipo
frontend-componente

## Arquivos a criar/modificar
- `resources/js/Composables/usePermissoes.js` -> criar
- `resources/js/Components/Sidebar.vue` -> modificar

## Contexto necessário (ler antes)
- `resources/js/Components/Sidebar.vue` -> itens de menu e uso de `$page`
- `app/Http/Middleware/HandleInertiaRequests.php` -> formato de `auth.user.permissoes` (Task 2.9)
- `.claude/skills/frontend-design-system/SKILL.md`

## Skills necessárias
- `.claude/skills/frontend-design-system/SKILL.md`

## Especificação

### O que fazer
1. `usePermissoes.js` expõe, lendo de `usePage().props.auth.user`:
   - `pode(permissao)` -> booleano, aceita string
   - `podeAlguma([...])` -> booleano
   - `temPapel(papel)` -> booleano
   - `ehAdministrador` -> computed
   Tudo em JavaScript puro, sem TypeScript, com guarda para `auth.user` nulo.
2. No `Sidebar.vue`, envolver cada item com `v-if`:
   - Clientes -> `pode('cliente-ver')`
   - Endereços -> `pode('endereco-ver')`
   - Orçamentos -> `pode('orcamento-ver')`
   - Cadastros -> `pode('cadastro-ver')`
   - Ordens de serviço -> `pode('ordem-servico-ver')`
   - Certificados -> `pode('certificado-ver')`
   - Contratos -> `pode('contrato-ver')`
   - Dashboard financeiro, Entradas, Saídas, Fluxo de caixa -> `pode('financeiro-ver')`
   - Configurações da empresa -> `pode('empresa-configurar')`
   - Dashboard -> sempre visível
3. Se um agrupamento do menu (por exemplo, o bloco Financeiro) ficar sem nenhum
   item visível, esconder também o título do bloco.

### Regras de negócio aplicáveis
- Esconder item de menu é conveniência visual. A proteção real está na rota.
- Não usar TypeScript. `<script setup>` em JavaScript puro.

### Critérios de aceitação
- [ ] Usuário com papel `tecnico` não vê nenhum item financeiro no menu
- [ ] Usuário com papel `financeiro` vê o bloco financeiro e não vê Configurações da empresa
- [ ] Administrador vê o menu completo, igual ao de hoje
- [ ] `npm run build` compila sem erro

## Teste esperado

- Verificação manual: logar com cada papel e conferir o menu
