# Task 2.1 - Instalar e configurar Spatie Permission

## Objetivo
Instalar o pacote `spatie/laravel-permission`, publicar config e migration, rodar a
migration e habilitar a trait `HasRoles` no model `User`.

## Tipo
config

## Arquivos a criar/modificar
- `composer.json` / `composer.lock` -> modificar (via `composer require`)
- `config/permission.php` -> criar (publicado pelo pacote)
- `database/migrations/*_create_permission_tables.php` -> criar (publicado pelo pacote)
- `app/Models/User.php` -> modificar

## Contexto necessário (ler antes)
- `app/Models/User.php` -> model atual, sem papéis
- `CLAUDE.md` -> convenções do projeto

## Skills necessárias
- `.claude/skills/laravel-arquitetura/SKILL.md`
- `.claude/skills/permissoes-e-multitenancy/SKILL.md`

## Especificação

### O que fazer
1. `composer require spatie/laravel-permission` (versão compatível com Laravel 11).
2. `php artisan vendor:publish --provider="Spatie\Permission\PermissionServiceProvider"`.
3. `php artisan migrate` (cria `roles`, `permissions`, `model_has_roles`,
   `model_has_permissions`, `role_has_permissions`). São tabelas novas, sem dado
   existente: migration segura para produção em um único passo.
4. Em `app/Models/User.php`, adicionar `use Spatie\Permission\Traits\HasRoles;` e
   incluir `HasRoles` no `use` da classe.
5. Remover do `$fillable` e do `casts()` o campo `is_technician`: a coluna não
   existe na tabela `users` (conferido no schema), é código morto que quebra
   `User::create()` com esse atributo.

### Regras de negócio aplicáveis
- Nenhuma permissão é criada nesta task. Só a estrutura.
- Não alterar `config/permission.php` além do publicado; ajustes de cache e de
  `teams` não entram neste plano (o isolamento por empresa é o Plano 4).

### Critérios de aceitação
- [ ] `php artisan migrate` roda sem erro e as 5 tabelas do Spatie existem
- [ ] `User::find(1)->assignRole()` está disponível (trait carregada)
- [ ] `is_technician` não aparece mais em `app/Models/User.php`
- [ ] `php artisan test` continua passando (suíte atual: RotinasAgendadasTest, BusinessDateTest)
