# Task 11.2 - Geração do código público, backfill e unique composto

## Objetivo

Gerar o código público de todo dispositivo existente, passar a gerar automaticamente nos novos e só então tornar a coluna obrigatória e única por empresa.

## Tipo

backend-logica

## Especificação

### O que fazer

1. `CodigoDeDispositivo::gerar()`: string de 10 caracteres do alfabeto `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (sem `I`, `O`, `0`, `1`, que o técnico confunde ao digitar), sorteada com `random_int`. Método `valido(string $codigo): bool` para o endpoint de leitura recusar entrada malformada antes de consultar o banco.

2. Evento `creating` em `Device`: se `codigo_publico` estiver vazio, gerar. Repetir a geração enquanto já existir código igual **na mesma empresa**, com no máximo 5 tentativas antes de lançar exceção.

3. `php artisan dispositivos:backfill-codigo`, com `--dry-run`: percorre `devices` com `codigo_publico` nulo em blocos de 500, gera o código de cada um e imprime um relatório com o total por empresa. Sem a flag, grava. O comando é reexecutável e ignora quem já tem código.

4. Migration final: `codigo_publico` NOT NULL e unique composto `[company_id, codigo_publico]`.

### Regras de negócio aplicáveis

- Alfabeto sem caractere ambíguo é o que permite o técnico digitar o código quando a câmera não lê, que acontece com etiqueta suja ou molhada.
- Unique é composto com `company_id`, e não global: duas empresas podem ter o mesmo código sem se enxergar.
- O código é **imutável** depois de gerado. Reetiquetar um ponto é substituição de dispositivo (Task 11.5), não alteração de código, porque etiqueta já impressa e colada continua no local.
- Três deploys separados: 11.1 (coluna nullable), backfill conferido, migration do NOT NULL. Nunca no mesmo deploy.

### Critérios de aceitação

- [ ] `dispositivos:backfill-codigo --dry-run` mostra o total por empresa sem gravar
- [ ] Rodar sem a flag preenche todos os dispositivos
- [ ] Rodar duas vezes não altera código já gravado
- [ ] Criar um `Device` sem informar código gera um automaticamente
- [ ] A migration final falha se sobrar algum registro sem código (comportamento esperado, e o operador roda o backfill antes)
- [ ] Nenhum código gerado contém `I`, `O`, `0` ou `1`
