# Task 9.8 - Telas de visitas do contrato e painel de pendências

## Objetivo

Mostrar as visitas previstas na tela do contrato, com geração sob demanda, e entregar o painel de contratos periódicos sem visita no período.

## Tipo

frontend-pagina

## Arquivos a criar/modificar

- `resources/js/Components/VisitasDoContrato.vue` -> criar
- `resources/js/Pages/Contracts/Show.vue` (ou a tela de detalhe existente) -> modificar
- `resources/js/Pages/Contracts/Pendencias.vue` -> criar

## Contexto necessário (ler antes)

- `resources/js/Pages/Contracts/` -> conferir o nome real da tela de detalhe antes de editar
- `app/Http/Controllers/ContractVisitController.php` -> dados enviados (Task 9.7)
- `resources/js/utils/formatDate.js` -> formatação de data
- `.claude/skills/frontend-design-system/SKILL.md` -> padrões visuais

## Skills necessárias

- `frontend-design-system`
- `datas-timezone`

## Especificação

### O que fazer

1. `VisitasDoContrato.vue`:
   - Linha do tempo das visitas: número, data, situação (agendada, concluída, cancelada, vencida) com etiqueta colorida, técnico quando houver, e link para a OS
   - Visita vencida não executada em destaque
   - Botão "Gerar visitas" quando faltarem, com resumo do que foi criado após a ação
   - Estado vazio explicando o motivo: contrato pontual, sem periodicidade, ou fora de vigência

2. Incluir o componente na tela de detalhe do contrato.

3. `Contracts/Pendencias.vue`: lista dos contratos com pendência, agrupada pelo motivo, com o número do contrato, o cliente, o motivo e o atalho para resolver (editar periodicidade ou gerar visitas). Ação de gerar em lote para os que só precisam disso.

### Regras de negócio aplicáveis

- Gerar em lote usa modal de confirmação com a contagem, nunca `confirm()` nativo.
- Datas formatadas pelos utilitários do projeto, jamais `toLocaleDateString`.
- O estado vazio precisa dizer **por que** está vazio. "Nenhuma visita" sem explicação faz o usuário achar que o sistema quebrou.
- Visita vencida não executada é o item mais importante da tela: ela precisa saltar aos olhos.
- Sem emoji.

### Critérios de aceitação

- [ ] A tela do contrato mostra as visitas previstas com situação e link para a OS
- [ ] Contrato pontual mostra o estado vazio com o motivo correto
- [ ] Contrato sem periodicidade mostra o motivo e o atalho para editar
- [ ] Gerar visitas funciona e mostra o resumo
- [ ] O painel de pendências agrupa por motivo e permite gerar em lote
- [ ] Visita vencida aparece destacada
- [ ] Responsivo em celular
- [ ] `npm run build` sem erro

## Teste esperado

- Comando: `npm run build`
- Verificação manual: abrir um contrato periódico, gerar as visitas, conferir a linha do tempo e o painel de pendências
