# Task 8.5 - Trilha de primeiros passos

## Objetivo

Indicar ao tenant novo o que falta configurar e marcar cada passo como concluído sozinho, quando a condição for satisfeita.

## Tipo

backend-logica

## Arquivos a criar/modificar

- `app/Support/PassosDeOnboarding.php` -> criar
- `app/Services/OnboardingService.php` -> criar
- `app/Http/Middleware/HandleInertiaRequests.php` -> modificar

## Contexto necessário (ler antes)

- `app/Models/OnboardingStep.php` -> criado na Task 8.1
- `app/Models/Company.php` -> campos que indicam empresa configurada (CNPJ, responsável técnico, logo)
- `app/Http/Middleware/HandleInertiaRequests.php` -> o que já é compartilhado
- `app/Support/CatalogoDeModulos.php` -> padrão de catálogo do projeto

## Skills necessárias

- `laravel-arquitetura`

## Especificação

### O que fazer

1. `PassosDeOnboarding::catalogo(): array`, cada passo com chave, título, descrição, rota de destino e a condição de conclusão automática:

   | chave | título | condição |
   |---|---|---|
   | `dados_empresa` | Complete os dados da empresa | CNPJ, endereço e telefone preenchidos |
   | `responsavel_tecnico` | Informe o responsável técnico | nome e título preenchidos em `companies` |
   | `logo_assinatura` | Envie logo e assinatura | `logo_path` e `signature_responsible_path` preenchidos |
   | `primeiro_cliente` | Cadastre o primeiro cliente | existe ao menos um cliente |
   | `primeiro_tecnico` | Cadastre um técnico | existe ao menos um técnico |
   | `primeira_os` | Emita a primeira ordem de serviço | existe ao menos uma OS |
   | `equipe` | Convide a equipe | existe ao menos um convite enviado |
   | `assinatura` | Escolha o plano | tenant tem assinatura ativa ou é interno |

2. `OnboardingService`:
   - `situacao(Company $empresa): array` -> por passo: concluído, ignorado ou pendente, mais o percentual do total
   - `avaliar(Company $empresa): void` -> roda as condições e marca os concluídos. Chamado de forma preguiçosa quando a trilha é exibida, não em toda requisição
   - `ignorar(Company $empresa, string $chave): void` -> o usuário pode dispensar um passo
   - `concluida(Company $empresa): bool` -> todos concluídos ou ignorados

3. Compartilhar `onboarding` no Inertia apenas enquanto a trilha não estiver concluída, calculado de forma preguiçosa.

### Regras de negócio aplicáveis

- Passo se marca sozinho pela condição. Depender de o usuário clicar em "concluí" produz trilha que nunca fecha.
- Passo pode ser ignorado. Trilha que não se pode dispensar vira ruído permanente para quem não quer aquele item.
- Tenant interno tem o passo `assinatura` concluído automaticamente.
- Trilha concluída some de vez e para de custar consulta.

### Critérios de aceitação

- [ ] `situacao()` devolve os 8 passos com estado e percentual
- [ ] Cadastrar o primeiro cliente marca o passo sozinho na próxima avaliação
- [ ] Ignorar um passo o tira do pendente sem marcá-lo como concluído
- [ ] Trilha concluída não é mais compartilhada com o frontend
- [ ] Tenant interno já nasce com o passo de assinatura concluído
- [ ] A avaliação não roda em requisição de quem já concluiu a trilha
