# Task 8.9 - Trilha de primeiros passos no dashboard

## Objetivo

Mostrar ao tenant novo o que falta configurar, com progresso e atalho para cada passo.

## Tipo

frontend-componente

## Arquivos a criar/modificar

- `resources/js/Components/TrilhaDePrimeirosPassos.vue` -> criar
- `resources/js/Pages/Dashboard.vue` -> modificar

## Contexto necessário (ler antes)

- `app/Services/OnboardingService.php` -> formato de `onboarding` compartilhado (Task 8.5)
- `resources/js/Pages/Dashboard.vue` -> dashboard atual
- `resources/js/Components/Card.vue` -> padrão de bloco
- `.claude/skills/frontend-design-system/SKILL.md` -> padrões visuais

## Skills necessárias

- `frontend-design-system`

## Especificação

### O que fazer

1. `TrilhaDePrimeirosPassos.vue`:
   - Barra de progresso com o percentual e o texto "X de 8 concluídos"
   - Lista de passos: concluído com marca e riscado, pendente com título, descrição curta e botão que leva à rota do passo, ignorado em cinza com opção de trazer de volta
   - Cada passo pendente tem a ação "dispensar"
   - O bloco inteiro pode ser recolhido, e o estado de recolhido persiste em `localStorage`
   - Não renderiza nada quando `page.props.onboarding` não vier (trilha concluída)

2. Incluir no topo do `Dashboard.vue`, acima dos cards atuais.

### Regras de negócio aplicáveis

- Trilha concluída some de vez. Bloco de boas-vindas permanente em sistema de uso diário é ruído.
- Recolher é diferente de dispensar: recolher esconde o bloco, dispensar tira um passo da conta.
- Sem emoji nos ícones; SVG inline como o restante do projeto.
- Nenhuma alteração nos cards atuais do dashboard.

### Critérios de aceitação

- [ ] A trilha aparece no topo do dashboard de um tenant novo
- [ ] O percentual e a contagem batem com os passos concluídos
- [ ] Clicar em um passo leva à tela correta
- [ ] Dispensar um passo o tira do pendente e atualiza o percentual
- [ ] Recolher persiste entre navegações
- [ ] Tenant com trilha concluída não vê o bloco
- [ ] Responsivo em celular
- [ ] `npm run build` sem erro

## Teste esperado

- Comando: `npm run build`
- Verificação manual: em um tenant novo, cadastrar um cliente e conferir que o passo fecha ao recarregar o dashboard
