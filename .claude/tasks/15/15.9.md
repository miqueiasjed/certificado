# Task 15.9 - Testes de isolamento do portal

## Objetivo

Provar que cliente A não alcança nada do cliente B nem do tenant, por nenhum caminho.

## Especificação

### O que fazer

1. `IsolamentoDoPortalTest`, cenário com duas empresas, dois clientes em cada e dados em todos:
   - **percorrer todas as rotas de `routes/portal.php` automaticamente**, lendo o roteador, e afirmar que cada uma devolve 404 ou lista vazia para dado de outro cliente. Teste que enumera as rotas do arquivo é o que impede uma rota nova nascer vazando;
   - id de outro cliente devolve 404 em todos os endpoints de detalhe;
   - id de outra empresa devolve 404;
   - documento de outro cliente devolve 404;
   - documento em rascunho não aparece na listagem nem por id;
   - nenhuma resposta contém campo de custo, margem ou comissão (percorrer o JSON de todas as rotas);
   - cliente autenticado recebe 403 ou redirecionamento em qualquer rota de `routes/web.php`;
   - usuário funcionário autenticado não alcança `/portal`.

2. `PortalAuthTest`: convite, token expirado, token reutilizado, mensagem idêntica nos três erros de login, limite de tentativas, e desativação derrubando o acesso na requisição seguinte.

3. `PortalServiceTest`: escopo duplo mantido mesmo com o escopo global desligado no teste; campo novo em model exposto não aparece sem entrar na lista de permissão.

4. Nenhum teste usa `actingAs` no guard errado sem afirmar o resultado.

### Regras de negócio aplicáveis

- Vazamento entre clientes é a falha mais grave deste plano, e o teste que enumera as rotas é o que o impede de voltar.
- O teste de escopo global desligado prova que o filtro por cliente é independente, e não uma consequência acidental do Plano 4.
- Teste de ausência de campo financeiro percorre o JSON, não confere apenas o que se lembrou de checar.

### Critérios de aceitação

- [ ] Os três arquivos passam
- [ ] O teste que enumera as rotas do portal está presente e cobre todas
- [ ] O teste com o escopo global desligado está presente
- [ ] O teste de ausência de campo financeiro percorre o JSON inteiro
- [ ] A suíte continua verde
