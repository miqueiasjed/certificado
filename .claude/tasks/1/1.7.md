## Especificação

### O que fazer

Criar o módulo com exportações nomeadas, JavaScript puro, sem dependência externa e sem TypeScript:

| Função | Entrada | Saída |
|---|---|---|
| `formatarData(valor)` | `2026-07-25` ou ISO | `25/07/2026` |
| `formatarDataHora(valor)` | ISO com hora | `25/07/2026 14:30` |
| `formatarDataExtensa(valor)` | `2026-07-25` | `25 de julho de 2026` |
| `formatarHora(valor)` | ISO ou `14:30:00` | `14:30` |
| `diasAte(valor)` | data | inteiro, negativo quando já passou |

Regras de implementação, nesta ordem:

1. **Data sem hora é tratada como texto.** Para uma string no formato `yyyy-MM-dd`, divida por `-` e monte a saída direto. Nunca instancie `new Date('2026-07-25')`: o JavaScript lê como UTC e devolve o dia anterior em fuso negativo.
2. **Instante é convertido explicitamente.** Para string ISO com hora, use `Intl.DateTimeFormat` com `timeZone: 'America/Sao_Paulo'`.
3. Toda função devolve `''` (string vazia) para `null`, `undefined`, string vazia ou valor inválido. Nenhuma função lança exceção, porque elas são chamadas direto no template.
4. `diasAte` compara dia contra dia, ambos no fuso `America/Sao_Paulo`, e devolve `0` para hoje. Devolve `null` para entrada inválida.
5. Exportar também um `default` com todas as funções, para permitir `import formatDate from '@/utils/formatDate'`.

Comentar no topo do arquivo, em português e em duas linhas, por que a data sem hora não passa por `new Date`.

### Regras de negócio aplicáveis

- Nenhuma outra implementação de formatação de data pode existir no projeto. Este é o arquivo único.
- Não use `toLocaleDateString`, `toLocaleString` nem `toLocaleTimeString` dentro do próprio utilitário.
- Formatação de moeda fica fora do escopo: `app.js` e `useMasks.js` usam `toLocaleString` para valores em reais e não devem ser tocados.

### Critérios de aceitação

- [ ] `formatarData('2026-07-25')` devolve `25/07/2026` independentemente do fuso do navegador
- [ ] `formatarData('2026-01-01')` devolve `01/01/2026` com o navegador em UTC-3 e em UTC+9
- [ ] `formatarDataHora('2026-07-25T23:30:00.000000Z')` devolve `25/07/2026 20:30`
- [ ] `formatarDataExtensa('2026-07-25')` devolve `25 de julho de 2026`
- [ ] Todas as funções devolvem `''` para `null` e para valor inválido
- [ ] `diasAte(hoje)` devolve `0`
- [ ] Nenhuma ocorrência de `toLocale` no arquivo
