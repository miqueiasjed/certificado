# Task 1.10 - Substituir formatação de data: telas financeiras

## Objetivo

Eliminar `toLocaleDateString` das telas de fluxo de caixa, painel financeiro, lançamentos e retiradas, sem tocar na formatação de valores em reais.

## Tipo

frontend-pagina

## Arquivos a criar/modificar

- `resources/js/Pages/CashFlow/Index.vue` -> modificar (1 ocorrência)
- `resources/js/Pages/FinancialDashboard/Index.vue` -> modificar (2)
- `resources/js/Pages/FinancialEntries/Index.vue` -> modificar (2)
- `resources/js/Pages/FinancialWithdrawals/Index.vue` -> modificar (2)

## Contexto necessário (ler antes)

- `resources/js/utils/formatDate.js` -> criado na Task 1.7, é a única fonte permitida
- `.claude/skills/datas-timezone/SKILL.md` -> seção 4

## Skills necessárias

- `datas-timezone`
- `frontend-design-system`

## Especificação

### O que fazer

Em cada arquivo:

1. Substituir apenas as chamadas `toLocale*` que formatam **data**, pelas funções `formatarData`, `formatarDataHora`, `formatarHora` ou `formatarDataExtensa`, conforme o caso.
2. Adicionar o import no `<script setup>`, importando somente o que o arquivo usa.
3. Remover funções locais de formatação de data e as chamadas a elas.

### Regras de negócio aplicáveis

- **Atenção redobrada com moeda.** Estas telas usam `toLocaleString('pt-BR', ...)` sobre número para formatar reais. Isso não é data e permanece exatamente como está. Antes de cada substituição, confirme que o valor formatado é uma data.
- Data de lançamento e data de saldo diário são dia (`date`), sem conversão de fuso. Filtro por período compara dia contra dia.
- Nenhuma alteração em cálculo, soma ou totalizador. Esta task é só apresentação.
- Não alterar layout, classe CSS nem texto.

### Critérios de aceitação

- [ ] `grep -rn "toLocaleDateString\|toLocaleTimeString" resources/js/Pages/CashFlow resources/js/Pages/FinancialDashboard resources/js/Pages/FinancialEntries resources/js/Pages/FinancialWithdrawals` não devolve nada
- [ ] Toda formatação de moeda continua intacta nos quatro arquivos
- [ ] `npm run build` compila sem erro
- [ ] Nenhum valor exibido no painel mudou, só a data
